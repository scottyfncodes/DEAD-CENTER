# Assets and licences

Everything DEAD CENTER ships, and where it comes from.

The game's artwork is HaveAnApp's own and proprietary (all rights reserved). `LICENSE.assets.json` records that in
machine-readable form for licence checks (`first_party: true`); it lives at the repository root, so it is not shipped.

| Asset | Files | Source | Licence |
|---|---|---|---|
| App icon | `public/icon.svg`, `public/icon-192.png`, `public/icon-512.png`, `public/apple-touch-icon.png` | Original artwork made for DEAD CENTER | Proprietary, all rights reserved (HaveAnApp) |
| Share image | `public/og.jpg` | Original artwork made for DEAD CENTER | Proprietary, all rights reserved (HaveAnApp) |
| Board, pieces and materials | `src/render/` | Generated in code at runtime (procedural walnut and brushed brass) | Project code |
| Sound | `src/audio/sound.ts` | Synthesised in the browser with Web Audio; no audio files | Project code |
| Fraunces (variable) | `@fontsource-variable/fraunces` | Undercase Type, via Fontsource | SIL Open Font License 1.1 |
| IBM Plex Mono | `@fontsource/ibm-plex-mono` | IBM, via Fontsource | SIL Open Font License 1.1 |
| three.js | `three` | three.js authors | MIT |
